# Project Layout

- `index.html` is the single-file web app and must remain at the top level for GitHub Pages.
- `spec.md` contains the project specification.
- `prompts.md` contains project prompts.
- `00_planning/` contains planning notes and sketches.
- `01_data/` contains data files.
- `02_validation/` contains hand calculations and test cases.
- `03_output/` contains screenshots and exported results.

Keep `index.html` as the only application source file at the top level. Save new files in the folder that matches their purpose, and do not place project notes, data, validation material, or output files in the repository root.
